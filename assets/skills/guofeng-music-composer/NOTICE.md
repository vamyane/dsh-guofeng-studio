# 来源与致谢（NOTICE）

本技能的理论部分依据公开出版的音乐理论教材、音乐院校教学资料、国家院团与官方文化机构资料、公开学术论文与专业音源厂商文档整理，并对网络资料做了筛选：

- 优先采用：音乐学院教材与课件（如黎英海《汉族调式及其和声》、民族管弦乐配器教材）、高校学位论文与期刊论文、国家/行业团体标准、非遗与院团官方资料、专业音源与采样器官网文档。
- 不采用：以"五音养生"为名的推销软文、SEO 洗稿站、无谱例的玄学文章、商品页。
- 关键事实（音程结构、和弦构造、乐器定弦与音域、戏曲声腔特征）均做多来源交叉核对；来源说法不一致或未能充分核实者，正文标注【待核实】，不做猜测、不编造数据。

## 关于案例

`references/07-案例与风格配方.md` 中的作品分析仅用于说明创作技法（调式、和弦进行、配器思路），属于评论与教学性质，**不提供、不复制任何作品的曲谱、音频或工程文件**，也不主张任何权利。作品名称与作者名仅作为分析对象被提及，权利归各自权利人所有。

## 关于乐器音色

MIDI 文件使用 General MIDI 音色号占位（如笛 → Flute 73、唢呐 → Shanai 111），这些音色由用户所用 DAW 或音源决定。本技能不随包分发任何采样、音源、SoundFont 或第三方音频素材。

## 第三方组件

本技能不包含任何第三方代码或库：三个脚本均为纯 Python 标准库实现。

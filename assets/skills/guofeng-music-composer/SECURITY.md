# 安全说明（SECURITY）

## 一句话

三个脚本只做「文本进、文本/MIDI 出」，不执行外部命令、不联网、不写系统目录。

## 脚本行为边界

| 脚本 | 读什么 | 写什么 | 是否联网 | 是否调用外部程序 |
|---|---|---|---|---|
| `guofeng_blueprint.py` | 可选的需求 JSON | 蓝图 Markdown / JSON | 否 | 否 |
| `jianpu2midi.py` | `.jp` 简谱文本 | `.mid` 文件 | 否 | 否 |
| `lint_guofeng.py` | `.jp` 简谱文本 | 校验报告 Markdown | 否 | 否 |

- 纯 Python 标准库实现（`argparse`、`json`、`pathlib`、`struct`、`datetime`、`math`），**不依赖任何第三方包**，因此不存在依赖供应链风险。
- 不做 `eval` / `exec` / `subprocess` / `os.system` 调用。
- 只写用户通过 `--out` / `--report` 指定、或位于当前工作目录的文件；不写系统目录、注册表、开机项。
- 输入异常（字段缺失、格式错误、小节时值不符）时走默认值或给出中文提示后退出，**不崩溃、不覆盖既有文件**。

## 用户侧建议

1. 从购买渠道获取技能包，不接收他人二次分发的修改版脚本。
2. 运行前确认 `--out` 指向自己期望的目录。
3. 如需核对，脚本全部为纯文本 Python，可直接阅读审计。

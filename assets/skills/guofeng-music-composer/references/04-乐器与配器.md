# 04 乐器与配器

> 解决：给每一件民乐写「它拉得动、像它自己」的声部，并把它们按频段与层次排开不打架。
> 何时读：工作流第 5 步配器；lint 报 M8（音域跨度超限）时回查。
> 硬约束：**第一节的 id、建议音域与 SPEC §4 一致**，脚本按它写 GM 音色与提示，不要改数。

脚本内固定写入 71（GM 无笙，Bassoon 近似）、105（Banjo）；演播时按 DAW 音源替换。

**记号**：`5,`=低八度 sol，`6'`=高八度 la，`1''`=高两个八度（与 `.jp` 的 `,/’` 同一套）。

**两套音域别混用**：
| | 用途 | 超了会怎样 |
|---|---|---|
|lint 判定（M8）| 只看**全曲音域跨度**（最高音与最低音的半音数）| >24 半音（约两个八度）→ warn；>30 半音 → error |
|建议音域（上表）| 选乐器、定音区、写谱 | **只给 info 级提示，不判错**（GM 与音源差异大，避免误伤）|

例：二胡建议音域 `5,–1''` 约 19 个半音，物理音域 d1–a4 有三个八度——按建议音域写谱最保险，配器时才知道高音区能上到哪。真正会判错的是**跨度超 30 半音**：`5,` 一直写到 `3''` 就一定报 error。

## 二、四组实操：能写什么、怎么避让

### 吹管组

|乐器|实际音域（记谱）|必写的技法|编曲角色|避让要点|
|---|---|---|---|---|
|笛 di|梆笛 d2–c4／曲笛 g1–e3|叠音、赠音、打音、颤音、吐音、花舌、循环换气|曲笛=副歌长旋律；梆笛=前奏/间奏华彩|高音区 2–4kHz 与人声抢，让 −2~3dB|
|曲笛 dizi_low|g1–e3|同笛，重气息|温润长音、文人段|与 di 不同时抢同一句|
|箫 xiao|d1–e3|气震音（5–6Hz）、滑音、叠赠打、轻吐|前奏氛围、主歌、孤独感|低音区音量小要 pad 垫；每 4–6 小节留气口|
|笙 sheng|14 簧 d1–e3／36 簧 c–c3|四五度和音、吐音、呼舌|和声黏合剂、宫廷/祭祀色彩|音量偏大，全奏时退 −3dB|
|唢呐 suona|a1–b3|循环换气、滑音（哭腔）、花舌、气拱音|高潮爆发、间奏"炸"一下|**不连续强奏超 4 小节**；不写弱奏|
|管子 guan|小管 a1–c4／中管 a–d3|唇压哨片、滑音、颤音|苍凉、西北、宗教|色彩乐器，一首 1–2 段|
|埙 xun|约一个八度|气息控制、滑音、气震音|引子、远古、独白|音域窄，只写 1–3 句，别做副歌|

### 拉弦组

|乐器|实际音域（记谱）|必写的技法|编曲角色|避让要点|
|---|---|---|---|---|
|二胡 erhu|d1–a4（常用 d1–d4）|**揉弦（长音默认）**、上/下/回/垫滑音、连弓、颤弓|叙事主角、副歌替人声走一遍|与高胡同 d2–a2 重叠→二胡 d1–d3、高胡 d2–d4；低音需大阮/革胡垫|
|中胡 zhonghu|g–d2|揉弦、长弓|中声部填充、加厚|不做独奏；与中阮抢 d1–e2|
|（高胡/板胡/京胡）|g1–d4／d2–g4／随腔|滑音、抛弓|广东音乐亮色／北方戏曲／京剧|SPEC 无独立 id：用 `erhu` 提高 8–12 度写法模拟，`@instrument` 仍写 `erhu`（乐器音域表只做 info 提示）|

### 弹拨组

|乐器|实际音域（记谱）|必写的技法|编曲角色|避让要点|
|---|---|---|---|---|
|古筝 guzheng|D–d3（21 弦五声定弦）|摇指、刮奏、琶音、**按滑（3→4、6→7）**、扫弦|清雅第一识别音、前奏刮奏|与吉他/钢琴中低区完全重叠→古筝走 c2 以上|
|古琴 guqin|C–d3|散音、泛音、按音、吟猱绰注|引子、文人、留白|一首用 1–2 次，多则廉价|
|琵琶 pipa|A–g3（25 品）|轮指、扫弦、滚奏、推拉、弹挑|侠气、武曲、节奏音型|与柳琴/古筝高音区打架；长音必靠轮指|
|阮 ruan|中阮 G–e2／大阮 C–a1|弹挑、扫弦、分解和弦、轮指|弹拨组和声骨架、替代吉他音型|大阮音量小，低音必须革胡/大提琴加强|
|扬琴 yangqin|G–g3|双竹、轮竹、琶音、颤竹、拨弦|弹拨组的"钢琴"、快速音型|全频段乐器，别与古筝同时走同一音型|

弹拨三条底线：① 不给弹拨写长音（除摇指/轮指）；② 不给拉弦写连续十六分音型（交扬琴/琵琶）；③ 中阮不放 sforzando 式旋律（它不抢眼）。

### 打击组（走 ch10）

|乐器|音高|写法|角色|避让|
|---|---|---|---|---|
|大鼓 daigu|无|正拍重击、滚奏推进|气势、心跳|不与 808/底鼓同拍砸|
|锣鼓组 luogu|无|锣鼓经：仓(重击)/顷(轻击)/台(小锣)/才·七·卜(铙钹重·轻·闷)/大(板鼓)/多罗(滚)/扎(拍板)|戏曲感、段落地基|大锣余音长，快段不用|
|堂鼓·木鱼·碰铃|无|堂鼓重击=冬；木鱼点；碰铃点缀|推进/禅意/清雅|余音长的不进快速段|

> GM 映射（SPEC §5）：BD=36、SD=38、HH=42、OHH=46、CRASH=49、大锣=52、小锣=53、堂鼓=45、木鱼=76、碰铃=37。

## 三、频段分区与避让（一段只让一件走旋律）

|频段|主力乐器|处理|
|---|---|---|
|高频 2k–4k+|笛、唢呐、二胡高音、板胡|与人声抢 → 让 −2~3dB 或退到乐句间隙|
|中高 400–2k|曲笛、扬琴、琵琶、古筝中音|只选 1 件在旋律线上|
|中 200–500|笙、中阮、箫中音|人声 300–500Hz 切一刀，让位|
|低 60–200|古琴低音、大阮、中胡、strings|三层叠：大阮+革胡+低音提琴，缺一则"飘"|
|亮点 6k+|板鼓、碰铃、指甲声|不削，这是"乐器味"|

四条硬规则：① 同频段不许两件齐奏同一旋律；② 二胡与中阮在 d1–e2 重叠，二胡走旋律时中阮只走和声；③ 古筝与吉他/钢琴同时用，古筝上移；④ 大阮不能替代电贝司。

## 四、配器递进模板（照层推进，别一上来全奏）

|层|编制|织体|放在哪段|
|---|---|---|---|
|1 独奏|1 件（箫/古琴/古筝/琵琶/二胡）|单线 + 留白|前奏头 4–8 小节|
|2 二重奏|2 件对话（箫+古筝、二胡+琵琶）|旋律 + 简单伴奏|前奏后段、桥段|
|3 小合奏|拉弦组 + 1 件弹拨|旋律 + 和声垫 + 节奏型|主歌|
|4 中合奏|加吹管（笛 + 笙）|旋律加厚|预副|
|5 大合奏|四组全奏|旋律+和声+节奏+低音+色彩|副歌|
|6 华彩|单件华彩或打击独奏|炫技|间奏|
|7 收尾|回到独奏/小型合奏|渐弱、留白|尾奏|

旋律传递三条路径：**由低到高**（大阮→中胡→二胡→笛→唢呐）；**由暗到亮**（箫→二胡→笛→全奏）；**由点到线**（古筝刮奏→琵琶→二胡→笛）。交接点必须同拍同小节、音色差要大、前件渐弱后件渐强。

## 五、与流行四大件的对应关系

|流行角色|民乐替代/叠加|写法|
|---|---|---|
|钢琴和声|笙 / 中阮 / 扬琴|笙走长音、中阮走节奏型、扬琴走琶音|
|吉他扫弦|中阮 / 琵琶|中阮分解、琵琶快速弹挑|
|贝司|大阮 / 革胡|大阮走低音线条，电贝司走节奏低音|
|主音吉他|二胡 / 笛 / 琵琶|二胡抒情、笛华彩、琵琶快速段|
|弦乐 pad|笙 + 中胡 + 中阮|三层叠成"民乐 pad"|
|架子鼓|板鼓 + 堂鼓 + 小锣|板鼓走中国味重音，架子鼓走流行律动|

## 六、六条常见错误（自查）

- [ ] 乐器堆砌：主歌就上全奏 → 按第四节分层。
- [ ] 频段打架：二胡与高胡同度齐奏 → 改八度叠加。
- [ ] 技法失真：给二胡写无揉弦无滑音的均匀音阶、给琵琶写长音和弦 → 按第二节技法列写。
- [ ] 低音缺失：只有高音与中音 → 大阮+革胡+大堂鼓三层。
- [ ] 气口缺失：给笛/箫/唢呐连写 8 小节 → 每 4–6 小节留气口。
- [ ] 音域跨度超 30 半音：一头写 `5,`、另一头写 `3''` → 收窄音域或换 `dizi_low`（M8 报 error）。

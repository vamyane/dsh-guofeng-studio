## 5. 乐器性格速查

| 要什么 | 选它 | 一句话 |
|---|---|---|
| 悲、倾诉 | 二胡 | 一把二胡顶半个主唱 |
| 远、孤、空 | 箫 | 越少越远，别连音 |
| 亮、田、少年 | 笛 | 高音区才有"亮" |
| 爆、喜庆、悲壮 | 唢呐 | 一响就是主角，别当铺底 |
| 水、颗粒、流水 | 古筝 | 刮奏 + 分解，副歌前最好用 |
| 沉、旧、留白 | 古琴 | 一个音就够，别堆 |
| 点、清脆 | 琵琶、扬琴 | 颗粒感靠短促，不靠音量 |
| 厚、托底 | 中胡、阮、弦乐组 | 铺底不留棱角 |
| 气势、心跳 | 大鼓、堂鼓 | 正拍重击，别填空 |

## 6. 九条门禁（交付前打勾）

- [ ] 偏音没做落音、没做长音？
- [ ] 终止音是调式主音？
- [ ] 五声正音 ≥70%？
- [ ] 小二度没扎堆（不像和风）？
- [ ] 大跳后有反向级进解决？
- [ ] 句尾有留白，不是匀速到底？
- [ ] 主奏民乐贯穿前奏/间奏/副歌？
- [ ] 旋律长音和和弦没撞小二度？
- [ ] 戏腔是为角色服务（或没用）？

## 7. 三条改稿急救

1. **像儿歌**：扩音域 + 加偏音经过 + 前紧后松节奏 + 高点挪到后半段。
2. **像和风**：把 3–4、7–1 小二度删掉，换成 2–3、5–6 大二度；尺八换成箫，太鼓换成堂鼓。
3. **前奏古、后面流行**：让主奏民乐在间奏/副歌再现同一动机；主歌让民乐做句尾叹息。

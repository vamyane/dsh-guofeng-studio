# 中国风音乐创作 · 使用说明（README）

一句话需求进，一套能开工的中国风方案出：**定调式 → 写简谱 → 配和声 → 出配器表 → 自动校验 → 导出多轨 MIDI**。

## 交付物

| 交付物 | 文件 | 说明 |
|---|---|---|
| 创作蓝图 | 蓝图 Markdown + JSON | 调式、音阶、结构时间轴、配器表、和弦候选、混音与避坑 |
| 简谱 | `.jp`（简谱 DSL）+ 可读简谱 | 旋律可改、可复跑 |
| 和弦表 | 级数 + 具体和弦 + 五声化写法 | 直接抄进 DAW |
| 配器与结构表 | 表格 | 乐器 / 出场段落 / 频段 / 声像 |
| 校验报告 | 校验报告 Markdown | M1–M15 规则 + 九大门禁，结论行"可交付" |
| MIDI | `.mid`（format 1，多轨） | 旋律 / 和声 / 低音 / 打击 + 段落标记，拖进 DAW 即用 |

## 快速开始

```bash
# 1. 出蓝图（空输入也能跑，全部字段可选）
python scripts/guofeng_blueprint.py --demo

# 2. 校验一首谱子（会给出逐条修法）
python scripts/lint_guofeng.py --input 我的谱.jp --report 校验报告.md

# 3. 导出 MIDI
python scripts/jianpu2midi.py --input 我的谱.jp --out 我的谱.mid
```

三个脚本都是**纯 Python 标准库**，Python 3.8+ 直接跑，不需要 pip 安装任何东西；不需要联网。

## 目录

- `SKILL.md`：技能工作流与硬规则（模型读这个）
- `references/`：九份可操作手册（速查卡、乐理调式、旋律写作、和声和弦、乐器配器、编曲结构、美学与戏曲民歌、案例与风格配方、九大误区与门禁）
- `scripts/`：三个脚本
- `samples/`：三首完整示范（抒情国风 / 古风戏腔 / 燃系国风）的简谱、和弦表、配器表与 MIDI

## 适用与边界

- 适用：短视频配乐、游戏/短剧 BGM、原创歌曲 demo、教学示例、编曲前期方案。
- 不适用：直接生成商业级成品音频；实录民乐演奏；替他人作品扒带转售。
- MIDI 使用 GM 音色占位，民乐质感取决于用户所用音源与演奏法处理。

## 配套技能

《中国风作词》（`guofeng-lyricist`）：韵辙句式、意象典故、化用边界、结构与金句、12 条词稿校验。两个技能可双向对接：

- 曲 → 词：把本技能的 `.jp` 交给作词技能，生成填词槽位表（每句字数、韵位、落音、声调建议）
- 词 → 曲：把作词技能生成的简谱骨架 `.jp` 交给本技能，直接导多轨 MIDI

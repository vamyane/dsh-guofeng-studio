# 隐私说明（PRIVACY）

## 一句话

**全程本地运行，不联网、不上传、不采集。**

## 具体说明

1. 本技能的三个脚本（蓝图生成、简谱转 MIDI、谱面校验）都是本地 Python 程序，**不发起任何网络请求**，不调用任何远程 API。
2. 脚本只读写用户明确指定的文件：
   - 读：用户输入的 `.jp` 简谱文件、需求 JSON 文件；
   - 写：用户指定路径的输出文件（蓝图、报告、MIDI）。
   未指定输出路径时，产物写在当前工作目录。
3. 不采集设备信息、不读取环境变量中的个人数据、不写注册表、不写用户目录以外的位置。
4. 不包含埋点、统计、遥测、崩溃上报。
5. 用户输入的音乐构思、歌词、主题属于用户自己，不经过本技能的任何外部通道。

## 数据留存

脚本运行结束后不在本地留存任何缓存（除用户自己指定的输出文件）。删除输出文件即彻底清除。

## 联系方式

如对隐私处理有疑问，请通过购买渠道的客服入口联系开发者。

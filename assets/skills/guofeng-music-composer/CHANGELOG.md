## v1.0.0 · 2026-10-25

首个版本。

### 新增

- **工作流**：需求解析 → 创作蓝图 → 简谱旋律 → 五声化和声 → 配器与结构 → 自动校验 → 多轨 MIDI 导出 → 变体建议，六步全链路。
- **脚本（纯标准库）**：
  - `scripts/guofeng_blueprint.py`：五套风格配方（抒情国风 / 古风戏腔 / 燃系国风 / 国潮电子 / 新民乐配乐），输入全可选，输出蓝图 Markdown + JSON（含结构时间轴、配器表、和弦候选、混音与避坑）。
  - `scripts/jianpu2midi.py`：简谱 DSL → format 1 多轨 MIDI（旋律 / 和声 / 低音 / 打击 + 段落 marker + tempo / 拍号 / 音色）。
  - `scripts/lint_guofeng.py`：M1–M15 规则校验 + 九大误区门禁清单，输出中文报告与退出码。
- **参考手册（九份）**：速查卡、乐理与调式、旋律写作法、和声与和弦、乐器与配器、编曲结构与节奏、美学与戏曲民歌、案例与风格配方、九大误区与门禁。
- **三首完整示范**：抒情国风、古风戏腔、燃系国风，含简谱、和弦表、配器表与可直接播放的 MIDI。

### 已知限制

- MIDI 使用 General MIDI 音色占位，民乐质感需在 DAW 中替换为真实音源并补演奏法（滑音、揉弦、轮指、刮奏）。
- 不支持从音频扒谱；不支持直接导出音频。
- 5/4、7/8 等非常用拍号暂不支持（4/4、3/4、2/4、6/8 可用）。

### 后续计划

- 简谱 DSL 增加装饰音与滑音标记，MIDI 端输出 pitch bend 表情。

# 示范 02 · 古风戏腔《惊鸿照影》

> 一句话需求：「写一首古风，戏台、旧梦、惊鸿一瞥，副歌要有一段戏腔。」
> 交付物：`demo02-古风戏腔-惊鸿照影.jp`（简谱 DSL）、`demo02-古风戏腔-惊鸿照影.mid`（5 轨）、本说明。
> 目的：演示「古风戏腔」配方——戏腔**只为角色服务、只用一段**，靠二胡拖腔 + 板鼓板眼撑住"戏"的气质。

## 一、需求 → 参数

| 参数 | 取值 | 依据 |
|---|---|---|
| 风格配方 | gudian 古风戏腔 | 用户明确要戏腔 |
| 调 / 调式 | G / 羽调式（主音 6 = E） | 羽调=柔中带悲，戏腔拖腔最顺 |
| 音阶 | 清乐（加 4、7） | 戏腔段用 4'、7 做装饰拖腔 |
| 速度 / 拍号 | 84 BPM / 4/4 | 配方区间 72–92 中段，慢而不散 |
| 主奏 | 二胡（erhu） | "悲、倾诉、如歌"，替代人声 |
| 时长 | 32 小节 ≈ 91.4 秒 | 戏腔段占 8 小节，比例克制 |

## 二、调式与音阶：为什么是 G 羽调 + 戏腔段

- 羽调主音 6，落音柔和；戏腔的"拖腔"最适合落在 6 和 3 上，不会像宫调那样一拖就"喜庆"。
- 戏腔的三个手段（本曲只用了两处，刻意克制）：
  1. **高音区拖腔**：第 21–28 小节整体上到 3'–6' 区；
  2. **装饰偏音**：第 25 小节 `3' 4' 5' 3'` 里 4' 只占 0.5 拍，第 26 小节 `6 7 1' 2'` 里 7 只占 0.5 拍——这是"戏味"来源，但绝不长留；
  3. 板鼓/锣鼓给"板眼"，让拖腔有"打"的对照。
- 戏腔只有一段：第 21–28 小节。前面主歌、副歌都是正常流行嗓的写法，**不全程戏腔**（门禁第 9 条）。

铁律：戏腔段**二胡让人声**（真做歌时主奏降 −3dB 或只做对位句），不要抢主唱位置。

## 六、旋律是怎么写出来的

1. **落音规划**：前奏落 6、主歌落 6、副歌落 6'、戏腔段落 6'、尾落 6——同一主音在三个八度上出现，形成"回声"结构。
2. **动机统一**：主歌 `6 1 2 3`、副歌 `3' 5' 3'`、戏腔 `6' 5' 3'` 都是同一个三音组（`3 5 6` / `6 1' 2'`）的移位，整首听起来是"一个动机在长大"。
3. **高点**：最高音 6' 出现在第 28 小节（全曲 87% 位置），符合"高点后移"。
4. **偏音**：只在戏腔段用两处（4'、7），各 0.5 拍，做装饰拖腔，不落音、不长留。
5. **留白**：第 12、20、28 小节末尾各留 1 拍，戏腔拖腔前必须"空出来"。

## 八、怎么改成你自己的

| 变量 | 怎么改 | 效果 |
|---|---|---|
| 戏腔位置 | 把 `@marks` 第 21 段改成 25 或 33 | 戏腔往后挪，前面多一段副歌 |
| 戏腔长度 | 8 小节 → 4 小节 | 宁可短，不要满 |
| `@instrument` | erhu → pipa / guzheng | 更"伶人"用琵琶，更"水"用古筝 |
| 速度 | 84 → 72 / 92 | 慢=更悲，快=更"急板" |
| 题材 | 戏台/伶人 → 闺怨/思乡 | 不是"戏中人"就**关掉戏腔**，改二胡+箫（见 `references/08-九大误区与门禁.md` 误区 9） |

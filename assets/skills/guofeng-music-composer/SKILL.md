# 中国风音乐创作 · SKILL

一句话需求进，一套能直接开工的中国风方案出：**定调式 → 写简谱旋律 → 配五声化和弦 → 出配器与结构表 → 跑校验 → 导出多轨 MIDI**。

这是「创作流水线 + 自动校验器」，不是乐理百科。默认动作是**直接产出完整方案**，不是反问用户。

## 一、触发场景

用户出现以下意图时使用本技能：

- 想写/编一首中国风、国风、古风歌，或某段配乐（影视、游戏、短剧、广告）
- 已有一段旋律或歌词，要配和弦、配器、编曲
- 指定题材（江南雨、边关、月下独酌、相思、江湖）要出音乐方案
- 要戏腔段、要燃、要国潮电子、要新民乐配乐感
- 要简谱、要和弦级数、要 MIDI 文件
- 写出来"像日本风 / 像儿歌 / 不像中国风"，要诊断并修

## 二、默认交付路径（用户只给一句话时）

用户只给一句需求（例如"写一首中国风，写江南雨"）时，**不要再问**，直接按以下默认值跑完整条链路，交付后在末尾列出可改参数：

| 参数 | 缺省 | 说明 |
|---|---|---|
| 风格 | `shuqing` 抒情国风 | 其它：`gudian` 古风戏腔、`ranxi` 燃系国风、`guochao` 国潮电子、`peiyue` 新民乐配乐 |
| 时长 | 180 秒 | 30–600 |
| 调 | D | 羽调式常用 D/`#F` 调；宫调式常用 C/G |
| 拍号 | 4/4 | 3/4、2/4、6/8 可选 |
| 主奏 | 按风格推（抒情=箫+古筝） | 见 references/04 |
| 人声 | 有 | 影响声部安排：副歌给主唱留 2–4kHz 空间 |
| 戏腔 | 否 | 只有"戏中人"题材才开，见 references/08 误区 9 |

## 三、工作流（6 步，每步都有产出）

### Step 1 · 需求解析 → 创作蓝图

```bash
python scripts/guofeng_blueprint.py --input 需求.json --out-md 蓝图.md --out-json 蓝图.json
```

需求 JSON 全部字段可选，缺省走默认值（**空 JSON `{}` 也必须能跑**）。蓝图包含：调式与音阶、五线/简谱对照、结构时间轴（每段起止小节与秒数）、配器表（乐器/音域/出场段落/声像）、3 套和弦进行候选（级数 + 具体和弦 + 五声化改造点）、节奏与打击乐方案、混音要点、避坑清单、下一步命令。

**不要跳过脚本手推参数**：蓝图脚本内置五套风格配方，参数与示例曲一致；手推会漂。

### Step 2 · 写旋律（简谱 DSL）

按蓝图的调式、落音规划、结构写 `我的谱.jp`（格式见第五节与 `samples/`）。写作要点：

1. **先定落音**：每段句尾先规划（主音=句号，属音=逗号，2/6=悬而未决），别每句都落主音。
2. **用三音组做材料**：1 2 3 / 3 5 6 / 5 6 i / 6 i 2 / 2 3 5，模进、倒影、加花都能长出来。
3. **级进为主，四度跳进收句**：80% 级进，四五度跳进放句首与高潮。
4. **高点放后半段**，高点音优先 5、6、1'，不要用 3 撑高潮。
5. **偏音只做经过/辅助**：`3 4 5`、`6 7 i` 一闪而过；**落在 4 或 7 上立刻变西洋**。
6. **留白**：句尾给 0.5–2 拍休止，中国音乐的"气口"比音符更重要。

### Step 3 · 配和声与配器

- 和弦优先从蓝图的 3 套候选里选，做五声化改造：`add9 / add2 / sus2 / sus4 / omit3` 替代三音齐全的大三和弦。
- **先看旋律长音再定和弦**：旋律停在 6，别配含 4 的下属；旋律 3 长音，别配含 4 的和弦（撞小二度）。
- 配器按 `references/04-乐器与配器.md` 的性格匹配：悲→二胡，远→箫，爆→唢呐，水→古筝刮奏。**主奏民乐必须贯穿前奏、间奏、副歌**，不能只在前奏响 10 秒。
- 每段做加减法：前奏 1–2 件，主歌少而准，副歌才加厚。

### Step 4 · 校验（门禁，必须跑到 0 error）

```bash
python scripts/lint_guofeng.py --input 我的谱.jp --report 校验报告.md
```

校验报告含 M1–M15 规则命中与「九大误区门禁清单」。**有 error 必须改到 0 error 再交付**；warn 逐条说明保留理由。规则含义见 `references/08-九大误区与门禁.md`。

### Step 5 · 导出 MIDI

```bash
python scripts/jianpu2midi.py --input 我的谱.jp --out 我的谱.mid
```

导出 format 1 多轨 MIDI（旋律/和声/低音/打击 + 段落 marker），可直接拖进任何 DAW，按 `references/04-乐器与配器.md` 换成真实民乐音源。GM 音色只是占位，交付说明里要写清替换建议。

### Step 6 · 交付与变体

固定交付物（缺一不可）：

1. 创作蓝图（`蓝图.md`）
2. 简谱（代码块里的 DSL，可直接改）
3. 和弦表（级数 + 具体和弦 + 五声化写法）
4. 配器与结构表（乐器 / 出场段落 / 频段 / 排布）
5. 校验报告（`校验报告.md`，结论行必须是"可交付"）
6. `我的谱.mid`
7. 一页创作说明：题材如何落到调式、主奏为何选它、下一版可换的 2–3 个变量

## 四、硬规则（违背即返工）

1. **偏音（4/7/#4/b7）不得做落音，不得做长音停留**（≥1 拍即算错）。
2. **全曲终止音必须是调式主音**：宫=1、商=2、角=3、徵=5、羽=6。
3. **五声正音占比 ≥70%**，偏音只做经过/辅助/倚音。
4. **小二度相邻进行要克制**：3–4、7–1 密集 = 和风预警；中国风以大二度、小三度为主。
5. **六度以上大跳后必须反向级进解决**，否则不像中国风。
6. **≥6 度跳进、过密十六分音符、连续同音**都要有呼吸，句尾留白。
7. **主奏民乐贯穿全曲**，不是前奏贴标签；民乐数量做减法。
8. **和声不与旋律撞色**：旋律长音优先选"和弦音都在五声里"的和弦。
9. **戏腔服务角色**：不是戏中人就不用戏腔；用了一段就够。
10. **只用五声音阶 ≠ 中国风**：必须同时做到调式色彩（宫明亮/羽忧郁）+ 主奏乐器性格 + 节奏留白三件事。

## 五、简谱 DSL 速查

```
@title 月下独酌
@key D
@mode yu            # gong|shang|jue|zhi|yu
@scale qingyue      # wusheng|qingyue|yayue|yanyue
@meter 4/4
@tempo 72
@instrument xiao
@style shuqing

@marks
1=前奏
9=主歌A
17=副歌

@melody
6 1' 2' 3' | 2' 1' 6 5 | ...

@chords
6m | 4add9 | 5sus4 | 1add9 |
```

- 音级 1–7，`#4`/`b7` 写偏音；`'` 高八度、`,` 低八度；`0` 休止。
- `音级:拍数` 控制时值，缺省 1 拍，如 `5:0.5`、`3:1.5`。
- 每小节拍数必须等于拍号，否则 lint 报 M12。

## 七、可用文件

- 脚本：`scripts/guofeng_blueprint.py`、`scripts/jianpu2midi.py`、`scripts/lint_guofeng.py`（全部纯 Python 标准库，无需安装依赖）
- 示范：`samples/` 下三首完整示范（抒情国风 / 古风戏腔 / 燃系国风）的简谱、和弦表、配器表、MIDI

## 八、与配套技能《中国风作词》的联动

两个技能各自独立安装、各自能单独用，但通过两种**文件格式**互通（对方不在也能跑）：

| 方向 | 怎么走 | 产物 | 交给谁 |
|---|---|---|---|
| 曲 → 词 | 本技能用 Step 5 导出 `.mid` 后，把 `.jp` 给作词技能；或直接说"给这首曲填词" | 填词槽位表 `.slots.json` + `.slots.md`（每句字数、韵位、落音、声调建议、断句位置） | 作词技能按槽位填词并校验 |
| 词 → 曲 | 作词技能用其 `lyric2jianpu.py` 把词变成简谱骨架 `.jp` | `.jp` 骨架 | 本技能直接 `python scripts/jianpu2midi.py --input 骨架.jp --out 成曲.mid` |

**推荐闭环**：本技能出 `.jp` → 作词技能生成槽位 → 填词 → 作词技能 lint → 微调成曲 → 回本技能导 5 轨 MIDI。

联动契约（文件字段）在两个包里都写在各自 SKILL.md；核心是：槽位表给"每句几个字、哪句押韵、落音在哪、哪几个字建议用平/仄"；简谱骨架给"每个字一个音、按四声走向生成、句尾落到调式主音"。

> 配套技能：《中国风作词》（guofeng-lyricist）——韵辙句式、意象典故、化用边界、结构与金句、12 条词稿校验，能把词变成简谱骨架，也能把曲变成填词槽位。

## 九、边界

- 本技能产出的是**创作方案与 MIDI 骨架**，不含实录音频、不含商业音源；成品混音需在 DAW 完成。
- MIDI 里的 GM 音色只是占位，民乐质感取决于用户所用音源与演奏法处理。
- 案例分析与技法说明来自公开教材、论文、院团与官方资料，存疑处已标注【待核实】；不保证复刻任何具体作品的版权素材。
- 生成结果可用于商业作品，但**素材与采样音源的授权由用户自行确认**；不提供对他人作品的扒带转售。

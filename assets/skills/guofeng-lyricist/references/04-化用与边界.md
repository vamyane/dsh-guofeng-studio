# 04 化用与边界（怎么"借"才高级，怎么"借"会翻车）

> 解决：想写出"有出处但不掉书袋"的句子——化用古诗不是抄，是取一层重写；同时守住不侵权的红线。
> 何时读：想借古人句/意象/句式时；交付商用词稿前自查时；客户说"像某某歌那样"时。
> 口径：思想与意境可自由借，表达（独特词串、完整意象链）不可搬。

## 一、五级化用阶梯（先定位，再动笔）

| 级别 | 做法 | 示例（情境＝"寻找后忽然发现"） | 判定 |
|---|---|---|---|
| L0 照抄 | 原句搬进歌词 | 直接引用原句 | 现代作品＝侵权；古诗＝集句掉书袋 |
| L1 换字 | 保留句式换实词 | 原句只换两三个字 | 太近，一听就认出 |
| L2 换语序 | 拆开重组 | 把长句改短、主谓倒装 | 勉强，仍薄 |
| L3 借节奏 | 借"长句→短句→转折亮底"的句法 | 长句铺垫，三字收，末句反转 | **合格线** |
| L4 借结构 | 借"热闹背景×冷清一人"的反差逻辑 | 换场景、换人物、换物象 | 好 |
| L5 借诗法 | 把叙事逻辑移植到全新题材 | 同一"寻找"逻辑写寻物/寻己 | 最好 |

**默认目标 L3 以上；L1–L2 只允许用在非名句，全篇最多 1 处。**

## 二、六个可直接操作的手法

| 手法 | 做法 | 自创示例 |
|---|---|---|
| 换骨 | 意思不变，整套物象换掉 | 写"久等"：茶温三遍、瓷沿先凉、门槛磨低一寸 |
| 夺胎 | 物象不变，情感指向翻转 | 月亮：热恋写"今晚不圆就不算分开"；悼亡写"照的人少了一个" |
| 拆句 | 一句古诗拆成"场景＋变化信号" | "楼还是那栋楼，风换了方向" |
| 词性活用 | 名词作动词，一首最多 1 处 | "把月色瓷了一遍"（慎用，需可解） |
| 句式借壳 | 借词牌句长节奏，不借字 | 长句铺、短句断、末句亮底（见 `references/01-词体与格律.md`） |
| 反用 | 把原典结论反转 | 原典"桃花依旧"是安慰 → 写成"桃花要是也走，我就信人会回来" |

## 二·五、用典配额与反堆砌（定稿口径）

### 1. 动笔前先过"一句话"

先用大白话说清**这首歌在说什么**（一句，不用典）：
- 「一个戏子等一个不会回来的人」
- 「灯会上找一个人，找了三年」

写完全篇再回头看这句话还在不在。**全篇只剩一串典、找不到这句话 = 拼贴，返工。**

### 2. 配额表（超出即判"堆砌"）

| 项 | 上限 | 超标后果 |
|---|---|---|
| 全篇用典 | **≤2 处**（短歌 ≤1） | ≥3 处＝拼贴感（lint L13 报 error） |
| 同一段落 | ≤1 处 | 一段双典，听众出戏 |
| 相邻两句 | 不得都用典 | 连续用典是最明显的拼贴特征 |
| 副歌首句 / 金句位 | **0 处** | 金句靠典＝没有自己的话 |
| 同一个典故 | 1 次 | 重复用典＝没词了（error） |
| 化用（非专名） | ≤2 处、L3 级以上 | 见本文第一节 |

### 3. 四种"堆砌症状"与改法

| 症状 | 例子（自创） | 改法 |
|---|---|---|
| 一句一典 | 庄周梦蝶／望帝春心／洛神凌波／阳关三叠，四句四个典 | 只留**与主题最贴的 1 个**，其余换成自己的物象 |
| 典故当形容词 | "像尾生一样等你" | 改成具体动作："水涨到腰，我还在桥下" |
| 同段双典 | 主歌两句分别用"兰亭""灞桥" | 删一个，把另一个写成场景而不是专名 |
| 副歌靠典撑 | 副歌首句"人面不知何处去" | 副歌首句必须自造，典挪到桥段或尾 |

### 4. 删典测试（逐句做，30 秒）

1. 把句中典故划掉，读一遍；
2. 仍成立/更好 → **删**（典是装饰）；
3. 不成立、信息缺失 → **留**（用在刀刃上）；
4. 留下后仍要问：删掉它，这首歌的核心表达有没有变弱？没变弱就是没用。

### 5. 核心表达优先（否则再雅的典也是空的）

- 全篇至少 **1 个贯穿物象**（灯、茶、门环、雪、伞……）反复出现 ≥2 次；
- 至少 **1 句自造金句**（无典、有具体物象、有动词、可独立成立）；
- 判断顺序永远是：**先有话 → 再找意象 → 最后才考虑用不用典**，不是倒过来。

> 对应校验：`lint_guofeng_lyric.py` 的 **L13（用典密度与堆砌）**、**L14（核心表达）**。全篇用典 >3 报 error，副歌首句用典报 warn，无贯穿物象/无自造金句报 warn。

## 三、四条铁律

1. **核心先行**：先有一句"这首歌在说什么"的大白话，再谈用典；删掉所有典后，这句话必须还在。
2. **取一不取二**：一个化用点只取"意象 / 句式 / 情绪"中的一层。
3. **典不过二**：全篇用典 **≤2 处**（短歌 ≤1），同段 ≤1，副歌首句与金句位 0 处，同典只用 1 次；≥3 处即判拼贴。
4. **必须注明**：交付词稿附「化用说明」（哪句化用什么、出处），并附「删典测试」结果。

## 四、红黄绿线（写词时逐条对照）

### 绿灯

- 唐宋诗词单句 ≤8 字的直接引用（公有领域；但连续引用多句会变"集句"）
- 用典故（神话/历史/文学事件），要求准确并注出处
- 借词牌句式、节奏、格律形式
- 用公共意象（月、雁、舟、梅、柳、灯）
- 用古人诗法（点铁成金、夺胎换骨）

### 黄灯（可做，但必须改到"不可识别"）

- 借现代国风作品**句法结构** → 只借通用句法（长句转短句），不借独特组合
- 借一个**独特意象链**（器物＋绘画＋人） → 换器物、换画面、换人称
- 同一词人的"词牌＋题材"组合 → 换韵辙、换视角
- 把现代作品一句改 2–3 个字 → **放弃，直接重写**

### 红灯

- 整句照搬现代歌词 / 只换数字地名的洗稿
- 整段经典作品当自己副歌
- 旋律与词一起搬（未授权改编）
- 在付费产品里内置他人歌词全文

## 五、可识别性自检三问（交付前必答）

1. 这 6–8 个字，是不是只有那一首作品会这么写？
2. 我是否借走了一个完整的"从 A 到 B 到 C"意象推进？
3. 读过原作的人，会觉得"偷得漂亮"还是"他抄了"？

任一答"是/不确定" → 重写。

## 六、安全重写四步

1. **只写意思**：一句大白话，不许出现任何原句词。
2. **拆三要素**：意象 / 句式 / 情绪，只留一个。
3. **换掉另两个**：换物象系统（器物↔自然↔声音），换句长。
4. **加你的细节**：具体数字、动作、地点（原创性最硬证据）。

示例：主题"等了很久人没来" → 只留情绪 → 换意象与句式 → 加细节：`茶梗沉下去又浮起来，第三遍 / 门没响`。

## 七、商用交付纪律

- 词稿必附「化用说明」；古诗化用也写清出处。
- 客户要"像某某歌" → 只给"像它的结构/情绪"，不给"像它的句子"。
- 案例拆解只讲手法，引用不超过连续 8 字，且标注"仅用于分析"。
- 遇到不确定的段落，宁可换一组意象重写，不要赌"应该没人发现"。

## 八、常见误区

| 误区 | 纠正 |
|---|---|
| 古诗无版权，随便用 | 用得太多变集句、失去原创性；且必须准确 |
| 改几个字就不算抄 | 判定看"接触＋实质性相似"，改字不改变实质 |
| 致敬就不算侵权 | 动机不是抗辩理由，商用要授权 |
| AI 生成不会侵权 | 生成物同样要过版权审查 |

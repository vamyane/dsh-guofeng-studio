# 05 炼字与修辞（速查）

用途：改稿阶段的"局部手术"。顺序：动词 → 名词 → 虚词 → 对仗 → 修辞。

## 一、动词替换表

**看**：看（中性）/ 望（远、期待）/ 顾（回头、牵挂）/ 凝（久、出神）/ 瞥（快、偶）/ 窥（偷看）/ 瞰（俯视）/ 盯（久不放）。

**常用义域**

| 义域 | 可换动词 | 提示 |
|---|---|---|
| 听 | 听／闻／聆／谛 | 聆配静景；谛只用于极细声 |
| 走 | 行／步／趋／踱／蹑／奔 | 踱＝来回；蹑＝轻；奔＝急乱 |
| 落 | 落／坠／堕／凋／谢 | 坠＝重快；堕＝失控；凋谢限草木 |
| 照 | 照／映／浸／染／漫 | 映＝水面返光；浸＝光如水；染＝带色 |
| 触 | 拂／掠／拭／扫 | 拂＝轻；掠＝快擦；拭＝有意擦 |
| 持 | 拿／捧／攥／捻／拈 | 捧＝珍重；攥＝用力；捻＝指细动 |
| 声 | 敲／叩／响／鸣／撞 | 叩＝轻恭；撞＝猛；鸣＝远传 |

## 二、20 组炼字对照（可直接套）

| 平句 | 炼后 | 炼在哪 |
|---|---|---|
| 月亮升上来了 | 月爬过檐角 | 慢、有过程 |
| 风吹动树梢 | 风梳过树梢 | 细密 |
| 雨下得很大 | 雨砸在瓦上 | 声与力 |
| 灯亮着 | 灯守着空屋 | 孤独（拟人） |
| 我很难过 | 我数着窗棂 | 动作代情绪 |
| 她走了 | 她带走了门外那双鞋 | 实物代"走" |
| 我想起从前 | 去年的酒还在柜里 | 物证时间 |
| 花开得好 | 花压弯了枝 | 重量感 |
| 水面有光 | 水捧着碎银 | 轻、珍重 |
| 烟往上飘 | 烟攀着梁 | 纠缠 |
| 他在等你 | 他站成一根桩 | 时间 |
| 时间过去了 | 铜壶滴穿了三更 | 力与慢 |
| 琴声很轻 | 琴声落成灰 | 通感＋落 |
| 山很高 | 山压着天 | 压迫 |
| 船在走 | 船咬住水 | 吃力 |
| 风吹过来 | 风从袖口灌进来 | 突入 |
| 眼睛很亮 | 眼里盛着一盏灯 | 容量 |
| 信没寄出 | 信在抽屉里发霉 | 结果说原因 |
| 他老了 | 他把巷子走旧了 | 使动，时间落物上 |
| 春天来了 | 春从瓦缝里钻出来 | 意外与力 |

## 三、虚词上限

| 虚词 | 上限 | 处理 |
|---|---|---|
| 的 | 每句 ≤1；副歌尽量 0 | 名词直接并置（"青石小巷"） |
| 了 | 每段 ≤1 | 用"早／已"替代 |
| 在 | 每首 ≤2 | 换动作（"数着窗棂"） |
| 是 | 每段 ≤1 | 意象直陈 |
| 而／之／其／以／于 | 每首 ≤2 | 多数可删 |
| 这／那 | 每段 ≤2 | 换具体物 |

**删虚词测试**：逐个删"的、了、在、这、那"再朗读，意思不变就删；删完节奏塌＝原句靠虚词凑字数。

## 四、名词具体化

| 抽象 | 换成实物（候选） |
|---|---|
| 愁 | 半盏冷茶／揉了又展的纸／没点的灯 |
| 思念 | 抽屉里的车票／没洗的茶杯／不敢接的铃声 |
| 往事 | 旧信封／褪色的糖纸／墙上的身高线 |
| 时间 | 更漏／香篆／指甲缝里的泥 |
| 等待 | 数第几班公交／门缝的光／凉了三遍的茶 |
| 孤独 | 两副碗筷／只响一声的拖鞋／满格电量 |

## 五、对仗四模板

| 模板 | 机制 | 自创例 | 放哪 |
|---|---|---|---|
| 正对 | 意同向，互相补画面 | 灯把窗纸映黄／雪把门槛垫高 | 主歌前两句 |
| 反对 | 意相反，造张力 | 来时满城花开／去时一径雪深 | 预副歌转折 |
| 流水对 | 一个动作两步，不可换序 | 我把灯点上／灯把影子推到墙上 | 副歌叙述 |
| 扇面对 | 隔句对（1 对 3、2 对 4） | 风翻旧信，字字都淡；雨打空阶，声声都慢 | 副歌四句、长调铺陈 |

**对仗六条件**：字数等、词性对、结构对、意义相关或相反、平仄相对（歌词可宽）、不重字。

**允许**：半对／差一字／流水对不严词性／借对／只副歌对。
**禁止**：合掌／为对而对倒语序／意象打架／全篇句句对。

## 六、五种修辞

| 手法 | 定义一句 | 自创例 | 每首用量 | 危险信号 |
|---|---|---|---|---|
| 通感 | 一种感官用另一种感官的词写 | 琴声落成灰／月色有点凉／她的名字有薄荷味 | 1—2 | 感官混到读不懂 |
| 借代 | 用相关物代本体 | 只剩半张车票／一把伞撑走整条雨巷／长安的灯不认识我 | 2—3 | 借代物读者不熟 |
| 双关 | 一词同关两义（谐音／语义） | 他说"留下"，石榴花正好开了／这盏灯叫"等"／门没锁，心锁了 | 1—2 | 需解释才懂、方言失谐 |
| 叠字 | 同字连用（AA/AABB） | 一圈一圈数到天白／慢慢走，慢慢老／重重叠叠的雨 | 1—2 | 变童谣、唱不下 |
| 倒装 | 变序强调或押韵 | 落了一地，是去年的雪／冷的是茶，不是人／提灯的人走在最前头，夜最深 | 1—2 | 还原后意思变了 |

**总原则**：修辞是局部手术。五样全上＝技巧展览；一样用准＝风格。

## 七、句式变化八法

倒装／省略／折腰（3+3、4+3）／领字（一字领、三字领）／叠句／设问／呼告／长短相间（3 接 9）。

## 八、改稿自检（六问）

1. 每个形容词能不能换成动词？
2. 每句虚词是否超上限？（的 ≤1、了每段 ≤1）
3. 抽象词是否都换成了能拍照的实物？
4. 副歌第 2、4 句是否押韵、句尾长音是否落韵脚？
5. 对句有没有合掌？有没有为凑对倒到听不懂？
6. 修辞是否超过用量？每一处能否说出"它解决了什么问题"？

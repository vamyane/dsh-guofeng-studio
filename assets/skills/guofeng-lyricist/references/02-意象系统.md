# 02 · 意象系统（写词查表用）

> 用法：选象前先定情绪 → 查「情绪配方」→ 套公式「主象+副象+动象」→ 过「禁忌表」→ 过自检。
> 三条铁律：**一象一情**（一物象只担一种情绪）、**主象不超二**（副歌金句主物象 ≤2）、**禁忌优先于美感**。

## 一、组合公式

```
主象（担情绪）+ 副象1（定天气/时间）+ 副象2（定地点/声音）+ 动象（人在场）
```

- 说人话就是：一个物象负责难过，两个物象负责布景，一个动作负责让人在场。
- 动象只用力动词：倚、折、掩、挑、回、凝、抚、吹、举、对、踏、剪。**禁用**「感/叹/念/殇」。
- 反例（伪古风）：「琉璃月下叹浮生，殇尽流年一场空」——0 个物象、0 个动作、3 个结论词。
- 正例：「楼头月满人未还」——主象月、副象楼、动象"未还"。

用法：每组分三拍写——第一拍出主象，第二拍补场景，第三拍落动作。**不要三拍都写物象**，第三拍必须有人。

## 四、通感链配方（视觉 → 听觉 → 触觉）

三拍同一场景，第三拍必须落到**可拍的身体**（温度/湿度/痛感），不许写"心房""灵魂"。

| 视觉 | → 听觉 | → 触觉 |
|---|---|---|
| 月白 | 砧声 | 衣薄 |
| 烛影 | 更鼓 | 掌心汗 |
| 雪光 | 折竹 | 颈后寒 |
| 荷风 | 橹声 | 发间湿 |
| 雁阵 | 笛声 | 肩头霜 |
| 灯火 | 笑语 | 袖底暖 |
| 铜镜 | 钗落 | 指节白 |
| 松涛 | 钟声 | 眉上湿 |

三禁：① 只堆视觉（三句全是颜色）＝幻灯片；② 跳过中介（"听见青色"）＝接不到；③ 把结论当触觉（"感到悲伤"）＝假通感。全篇通感 ≤2 处。

## 五、四类禁忌（写完必过）

### 1. 时空错乱（杀伤力最大）
写词前先定**唯一时空锚点**（朝代/地域/季节/时辰），所有物象服从它。

| 物象 | 出现/普及 | 早于此朝代要换 |
|---|---|---|
| 青花瓷 | 唐有雏形，元成熟（通行按元代成熟） | 汉代改用漆器/陶 |
| 椅凳（垂足坐） | 汉魏胡床 → 宋普及 | 汉魏写席/榻/胡床 |
| 玻璃镜 | 明清普及 | 唐宋写铜镜/菱花镜 |
| 折扇 | 北宋传入、明大盛 | 唐代写团扇/纨扇 |
| 烟花 | 宋 | 汉代写庭燎/灯 |
| 唢呐 | 明 | 明前写笛/笙/箫/鼓 |
| 二胡（奚琴） | 唐 | 汉代写羌笛/胡笳/琵琶 |
| 棉布 | 宋末元初 | 汉代写麻衣/裘/絮 |
| 蒸馏白酒 | 元 | 唐宋写酒/醪（低度） |
| 辣椒/玉米/土豆 | 明 | 明前不出现 |
| 桌（高足家具） | 宋 | 汉写几/案/席 |
| 眼镜/钟表 | 明 | 一律删 |

场所/身份也查：闺阁不进军帐、沙场不抚闺中筝、深宫听不见连营鼓角（除非给"梦/信/风/忽闻"通路）。

### 2. 物候错误
- 梅雨只在江淮（约 6 月中入梅、7 月上出梅）；**北方无梅雨**。
- 花期：梅（江南 2–3 月）→桃/梨（3–4 月）→荷（6–9 月）→桂（9–10 月）→菊（9–11 月）。
- 动物：雁秋南飞、燕春归、蝉鸣夏秋、蛩鸣秋、捣衣在秋。
- 时令：上元正月十五、清明四月上旬、七夕七月初七、中秋八月十五、重阳九月初九。

### 3. 逻辑冲突
同句互斥：日/月、雪/荷、霜/蝉、霜/盛夏、烈日/残雪、银河/白昼。
因果必正向；媒介必通（声音要给出进入室内的通路）；一句内不做"指间→万里"的尺度跳跃。

### 4. 雅俗混搭
现代工业词、品牌名、网络流行语一律不进正文。**唯一例外**：全曲设定就是古今对撞（国潮/都市国风），且满足三条——
① 全曲设定统一；② 至少一处意象桥（映/化/听/似）；③ 现代物只当"对照物"，不当抒情主体。
·反例：青花瓷配霓虹，你笑得绝绝子
·正例：青花瓷映霓虹，古今都一笔糊涂

### 附：抽象词黑名单（不是物象）
殇、琉璃（作抽象用）、浮生、流年、三生、彼岸、忘川、执念、宿命、红尘（抽象用）。
判别法：**能否被摄像机拍下来**。拍不下＝不是意象，是结论。

## 六、自检 10 条

1. 全篇时空锚点唯一？
2. 器物都在年代表内？
3. 身份与场所匹配？
4. 南北物候对得上？
5. 同句无互斥意象？
6. 因果正向成立？
7. 声音有"进入"通路？
8. 无品牌名/网络语/翻译腔？
9. 无抽象词冒充物象？
10. 国潮混搭有桥、有统一设定？

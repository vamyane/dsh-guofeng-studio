# 09 · 案例拆解（速查）

> 原则：只拆**结构/手法/用典/意象**，不提供可抄的句子；引用原句不超过连续 8 字且只在必要处标注"仅用于分析"。
> 三个可迁移的叙事轴：**器物轴**（青花瓷式）、**行动轴**（千百度式）、**角色轴**（戏腔/古风圈）。
> 拆解曲目 6 首：青花瓷、千百度、赤伶、牵丝戏、新贵妃醉酒、卷珠帘。

## 一、六曲速查

| 曲目 | 角色/叙事轴 | 一句话结构 | 可迁移手法 | 禁抄 |
|---|---|---|---|---|
| 青花瓷 | 器物轴（瓷） | 制胚→勾勒→上釉→落款→传世；把"你"写进每道工序 | 工序当时间线；动词转场；颜色词统一韵脚；以物作结 | 原句；素胚/天青/芭蕉/骤雨/锦鲤/仕女等组合 |
| 千百度 | 行动轴（寻找） | 关外→江湖→灯市，一路"寻你"；结尾你仍缺席 | 标题用典；空间位移代时间；重复+数字；结尾给缺席 | 辛词原句；原作句与题名；关外野店瘦马整套 |
| 赤伶 | 角色轴（戏子） | 台后身世 ↔ 台前唱戏；乱世里戏还得唱 | 台前台后双线；副歌戏腔拔高；念白交代身份 | 原作句；具体身世桥段 |
| 牵丝戏 | 角色轴（傀儡） | 用"线"写控制与被控制，最终线断 | 一个道具贯穿全曲；戏腔段冷、直、少装饰 | 原作句；傀儡与线的情节组合 |
| 新贵妃醉酒 | 角色轴（贵妃/伶人） | 宫廷爱情 + 醉后独白；真假声切换 | 男女声/真假声对话式结构；醉态视角 | 原作句；"贵妃醉酒"的既有唱段 |
| 卷珠帘 | 角色轴（闺中人） | 以"卷帘"动作起兴，等待与追忆 | 题名化用古诗；动作起兴；假声拖腔收句 | 原作句；李白《怨情》原句 |

## 二、三条叙事轴对比

| 维度 | 器物轴（青花瓷式） | 行动轴（千百度式） | 角色轴（戏腔/古风圈） |
|---|---|---|---|
| 推进器 | 工序（时间） | 行走/寻找（空间） | 身份与舞台（内外） |
| "你"的位置 | 被写进物里，在场 | 始终缺席，靠寻找存在 | 观众、亡者、旧人、或"另一个自己" |
| 转场工具 | 动词（勾勒、渲染、烧制） | 地点（关外、江湖、灯市） | 动作（上妆、上场、谢幕、封箱） |
| 结尾 | 物还在，人退场 | 人还在走，答案不在 | 戏散了，退回"人" |
| 适合题材 | 相思、传承、怀旧 | 寻人、悼亡、执念、江湖 | 伶人、傀儡、将军、宫廷、仙侠 |
| 韵辙倾向 | 颜色词统一韵脚 | 数字/时间词统一韵脚 | 宽辙（江阳/中东）便于拖腔 |

## 三、青花瓷式：手法清单（器物叙事）

| # | 手法 | 操作 | 检查 |
|---|---|---|---|
| C1 | 选有工序的物 | 瓷、茶、酒、扇、琴、纸、墨、绣、灯 | 工序能被专业人士认可 |
| C2 | 一段一工序 | 每段只推进一道，不跳步 | 段序 = 工序序 |
| C3 | 动词转场 | 勾勒→渲染→描摹→临摹→落款 | 不用"然后/接着" |
| C4 | 颜色词做线索 | 青/白/蓝（茶：青黄褐；酒：白/琥珀） | 副歌韵脚统一 |
| C5 | "等"字造悬置 | 把工艺条件写成等待（火候/湿度/季节） | 一句能同时成立工艺+自然+情感 |
| C6 | 你写进工序 | 你被画/被写/被包/被寄 | "你"不是旁白 |
| C7 | 时空各跳一次 | 现场→千里之外→千年之后 | 跳完要回到物 |
| C8 | 以物作结 | 物留在现在（旧箱、展柜、某人手里） | 人退场，不升华 |

**模板**：`物有 N 道工序 → 写 N 段 → 每段"我做什么 + 你在哪里" → 末段物留存`。

## 四、千百度式：手法清单（化用宋词 + 叙事层叠）

| # | 手法 | 操作 | 检查 |
|---|---|---|---|
| Q1 | 标题用典 | 取原典母题词（寻找/等待/归来） | 不取原句 |
| Q2 | 借题旨不借句 | 只借"找一个人"的动作 | 连续相同 ≤7 字 |
| Q3 | 宋词句法 | 三字顿、四字句、虚词（怎/谁为/只是/可）、问句收段 | 读起来有词味 |
| Q4 | 空间位移代时间 | 关外→渡口→灯市 | 每段换空间 |
| Q5 | 重复 + 数字 | 副歌同句重复，插"千百度/一岁/三四更" | 重复 ≤4 次 |
| Q6 | 今昔/梦醒层叠 | 主歌梦、副歌醒；或主歌昔、副歌今 | 两层有一件共同物 |
| Q7 | 结尾给缺席 | 把原典的"找到"改成"没找到/来不及" | 不改题旨，只改答案 |
| Q8 | 雅俗混用 | 文言骨架 + 口语短句 | 不整段文言 |

**模板**：`一句宋词定题旨 → 三字顿写场景 → 空间推进三段 → 副歌重复寻找 → 结尾缺席`。

## 五、戏腔/古风圈：角色化 + 念白 + 拖腔

### 5.1 角色化五步

1. 定行当（戏子/傀儡/将军/闺秀/道士）；
2. 给身份道具（妆、箱、线、翎子、水袖、髯口）；
3. 台前台后双线（后台写苦、台前写光），用"上场/谢幕"切换；
4. 行话点睛 1–3 个（吊嗓、倒仓、碰头彩、封箱、检场）；
5. 结尾退回"人"（戏散后去哪、吃什么、睡不睡得着）。

**行话可用度**：水袖/吊嗓/倒仓/碰头彩/封箱=高；翎子/髯口/厚底/起霸=中（**注意行当搭配，别给书生插翎子**）；检场=中（小人物视角）。

### 5.2 念白 vs 唱词

| 维度 | 念白 | 唱词 |
|---|---|---|
| 句长 | 4–9 字 | 5–14 字 |
| 停顿 | 多 | 少（靠拖腔连） |
| 语言 | 口语/韵白 | 书面/诗化 |
| 押韵 | 可松 | 必须同辙 |
| 作用 | 交代、转折、自嘲 | 抒情、拔高、记忆点 |
| 最佳位置 | 开场 / 副歌前 / 结尾 | 主歌 / 副歌 |

### 5.3 戏腔段字数与拖腔

| 句型 | 字数 | 音区 | 一字多音 | 句尾 | 韵辙 |
|---|---|---|---|---|---|
| 高音短句 | 4–7 | 高 | 少（1–2 音/字） | 短收、顿住 | 江阳、中东 |
| 拖腔长句 | 10–14 | 中高 | 多（3–6 音/字） | 延长 2–4 拍 | 言前、江阳 |
| 念白 | 4–9 | 中 | 无 | 停顿 | 可松 |

**四条硬规则**：①副歌短长交替，不连排同长度；②锁宽辙（江阳/中东），避入声短促字做尾；③长句第 4–6 字标气口；④高音句用开口呼（a/ang）。

### 5.4 戏腔结构模板

```
主歌A（白嗓叙事 8）→ 副歌一（戏腔 6/10–12 交替 8）→ 主歌B（白嗓 7–8）
→ 副歌二（戏腔高潮，可"一唱…八唱"）→ 念白（4）→ 尾（4，退回人）
```

## 六、化用边界（红线）

| 行为 | 判定 | 做法 |
|---|---|---|
| 连续 8 字以上与原作相同 | 抄袭风险高 | 改写到 ≤7 字且骨架不同 |
| 换字不换句（只改 1–2 字） | 抄袭 | 换句式、换意象、换视角 |
| 借题旨/借结构/借句法 | 允许（化用） | 注明灵感来源更稳 |
| 引用原句并标注致敬 | 有条件允许 | 极短、明确、非商用优先 |
| 照搬意象组合（如"关外野店瘦马"） | 高风险 | 至少换 3 个核心物 |

## 七、案例拆解自检

- [ ] 是否写清了角色"靠什么吃饭"？
- [ ] 是否有一条贯穿的物/动作（器物、寻找、线、戏箱）？
- [ ] "你"在结构里是否始终有位置（在场或被寻找）？
- [ ] 转场是否靠动作/物，而不是"然后"？
- [ ] 结尾是否从物/角色退回"人"或留给"物"？
- [ ] 引文是否 ≤8 字且标注用于分析？
- [ ] 是否只借了手法，没有借句子？

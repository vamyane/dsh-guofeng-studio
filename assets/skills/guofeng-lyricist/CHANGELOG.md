# 更新日志（CHANGELOG）

## v1.0.1 · 2026-10-25

### 新增

- **反堆砌门禁**：新增 lint 规则 **L13 用典密度与堆砌**（全篇用典 >3 报 error、=3 warn、同段 ≥2 warn、相邻两句都用典 warn、副歌首句/金句位用典 warn、同一典故重复 error），**L14 核心表达**（全篇需有贯穿物象 ≥2 次 + 至少一句不靠典的自造金句，否则 warn；并输出"删典测试"清单）。
- **用典配额写进规则**：全篇 ≤2 处（短歌 ≤1）、同段 ≤1、副歌首句与金句位 0 处、同一典故 1 次；`references/03-典故与用典.md` 新增「用典配额与位置」表，`references/04-化用与边界.md` 新增「用典配额与反堆砌」（四种堆砌症状与改法、删典测试、核心表达优先）。
- 蓝图脚本的典故候选标注配额；避坑新增"典故拼贴"一条。
- 十三辙字表补充常用字（慢/珊/烟→言前、响→江阳、文→人辰），减少"无法自动归辙"提示。

### 未变

- 工作流、四个脚本接口、示范词均向后兼容。

## v1.0.0 · 2026-10-25

首个版本。

### 新增

- **六步工作流**：需求解析 → 作词蓝图 → 结构句式韵辙 → 意象典故 → 化用炼字 → 校验 → 交付（词稿 + 蓝图 + 报告 + 化用说明 + 成曲对接）。
- **四个纯标准库脚本**：
  - `scripts/lyric_blueprint.py`：主题/情绪 → 韵辙推荐、词牌句式候选、意象包、典故候选、结构卡、金句位、可复制 `.lyr` 骨架。
  - `scripts/lint_guofeng_lyric.py`：L1–L12 规则校验（韵脚、句长、倒字、重复、伪古风词、时空错乱、典故、生僻字、结构、AI 味、金句、断韵）+ 门禁清单 + 退出码。
  - `scripts/jianpu2lyricslots.py`：读取配套作曲技能 `.jp` 曲谱 → 生成填词槽位表（每句字数、韵位、落音、声调建议）。
  - `scripts/lyric2jianpu.py`：词稿 → 依字行腔生成五声简谱骨架 `.jp`，可直接交给作曲技能导 MIDI。
- **十一份手册**：速查卡、词体与格律、意象系统、典故与用典、化用与边界、炼字与修辞、声韵与腔词、主题与题材库、结构与叙事、案例拆解、反模式与自检。
- **四组示范**：曲填词（配《江南雨》曲）、化用式《灯火阑珊》、戏腔式《梨园旧梦》、词作曲《山月不知》。

### 已知限制

- 不生成人声演唱音频；不提供他人作品歌词全文。
- 韵辙判定按声乐/台词教学主流口径（üe→乜斜、-eng/-ing→中东）；个别字在《汉语知识词典》一系另有归法，报告与资料库中以括注说明。
- 不支持严格按词牌填词（只借句式节奏，不校验每个字的平仄谱）。
- 生僻字判定以 GB2312 一级字为界，专业古字会被提示但不是错误。

### 后续计划

- 严格词牌填词模式（平仄谱校验）。
- 与作曲技能的深度联动：按旋律自动推荐句长与重音位置的最优词序。
- 方言韵（粤语九声、吴语）填词支持。

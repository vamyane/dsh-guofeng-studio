# 中国风作词 · SKILL

给一个主题，出一首**能唱、有出处、不掉书袋**的中国风词；如果手里已经有曲，就出一张能直接填的**填词槽位表**；如果先有词，就出一份能直接导 MIDI 的**简谱骨架**。

这是「创作流水线 + 自动校验」，不是诗词百科。默认动作是**直接产出完整词稿**，不是反问。

## 一、触发场景

- 要写中国风 / 国风 / 古风歌词，给主题、情绪、意象就行
- 已有歌词：润色、改韵、去 AI 味、去伪古风、改金句
- 已有曲（`.jp` 简谱）：要填词，要每句字数和韵脚位置
- 先有词：要配旋律，要能导出 MIDI
- 客户说"要像青花瓷 / 千百度那样"，需要拆手法而不是抄句子

## 二、默认交付路径（用户只给一句话时）

不反问，直接按默认值跑完整条链路，交付后列出可改参数：

| 参数 | 缺省 | 说明 |
|---|---|---|
| 题材 | 由用户关键词推 | 相思 / 离别 / 怀古 / 家国 / 江湖 / 隐逸 / 悼亡 / 少年 / 市井 / 禅意 |
| 人称 | 第一人称「我」 | 男女声、第二人称「你」可指定 |
| 体式 | 四段体 | 主歌A–主歌B–副歌–尾，每段 4 句 |
| 韵辙 | 由情绪推（哀→人辰/言前，亮→江阳，远→遥条） | 十三辙，整段一辙到底 |
| 句长 | 主歌 7–10 字、副歌 8–12 字 | 也可给词牌按句式谱 |
| 用典 | ≤3 处 | 超过即掉书袋 |
| 化用 | ≤2 处、L3 级以上 | 见 `references/04-化用与边界.md` |

## 三、六步工作流

### Step 1 · 需求 → 作词蓝图

```bash
python scripts/lyric_blueprint.py --input 需求.json --out-md 作词蓝图.md --out-json 作词蓝图.json
```

输入全可选（空 JSON `{}` 也能跑）。蓝图给：韵辙推荐（1 主 2 备 + 理由）、句式/词牌候选 3 套（每句字数 + 韵位）、意象包 3 组（每组 6–8 个物象）、典故候选 3–5 条（出处 + 一句示范）、结构卡（段落/句数/字数/韵位/金句位）、参考案例（只给手法）、避坑 5 条、可直接复制的 `.lyr` 骨架。

**不要跳过脚本手推参数**：韵辙与情绪、句长与段落、意象与题材的对应关系在脚本内置表里，手推会漂。

### Step 2 · 定结构、定句式、定韵

- 主歌**叙事**（密、口语、有镜头），副歌**抒情**（疏、金句、韵脚可拖长），桥段**转折**（换视角/换时态）。
- 每段 4 句，偶句押韵（2、4 句），句尾必须是长音或休止位。
- 一韵到底；要换韵则整段换（段落转折处），不在段内换。
- 需要古意就借词牌句长节奏（见 `references/01-词体与格律.md`），不必严格填词。

### Step 3 · 配意象与典故

- 一象一情：每个意象都要承担情绪或推进叙事，不做装饰。
- 一首词只用一个"意象系统"（器物向 / 自然向 / 声音向），不要三套混用。
- 典故 ≤2 处，且必须服务叙事；**副歌首句与金句位不用典**；用典四法见 `references/03-典故与用典.md`，配额见 `references/04-化用与边界.md`。
- **反堆砌**：一句一个典＝拼贴；每处用典过"删典测试"（删掉后句子仍成立就删）。
- 禁止抽象堆砌：能不写"殇、琉璃、浮生、缱绻、流年"就不写。

### Step 4 · 化用与炼字

- 化用按 L3 以上做：取意象 / 句式 / 情绪中的**一层**重写，不搬词。
- 动词优先：每句至少一个具体动作（推、磨、沉、覆、数、候）。
- 虚词节制：每段"的/了/着"≤2 个；古意句里尽量不用。
- 通感一处即可，多了变怪。
- 完整方法与红线见 `references/04-化用与边界.md`。

### Step 5 · 校验（门禁，必须 0 error）

```bash
python scripts/lint_guofeng_lyric.py --input 我的词.lyr --report 校验报告.md
# 有曲就带上：--jp 我的曲.jp   有槽位就带上：--slots 我的槽位.slots.json
```

L1 韵脚一致 / L2 句长 / L3 倒字 / L4 重复 / L5 伪古风词 / L6 时空错乱 / L7 典故 / L8 生僻字 / L9 结构 / L10 AI 味 / L11 金句 / L12 断韵 / **L13 用典密度与堆砌** / **L14 核心表达**。**error 清零再交付**；warn 逐条写保留理由。

### Step 6 · 交付

固定交付物（缺一不可）：

1. 词稿 `.lyr`（逐字标声调，可直接喂给谱曲脚本）
2. 可读版词稿（分段、每句一行，标注韵脚字）
3. 作词蓝图（`作词蓝图.md`）
4. 校验报告（结论行必须是"可交付"）
5. 「化用与用典说明」（哪句化用什么、出处）+「删典测试」结果
6. 成曲路径：曲→词给填词槽位表；词→曲给简谱骨架 + 与作曲技能的对接命令

## 四、硬规则（违背即返工）

1. **一韵到底**：段内不换辙；副歌韵脚必须押在句尾长音上。
2. **句长服务旋律**：主歌 5–12 字、副歌 6–14 字；有槽位时按槽位 ±2。
3. **句尾不倒字**：韵脚与重音字的声调必须与旋律走向一致（见 `references/06-声韵与腔词.md`）。
4. **用典 ≤2 处（短歌 ≤1）、同段 ≤1、同一典故只用 1 次**；**副歌首句与金句位 0 用典**；每处用典必须过"删典测试"（删掉后句子仍成立 = 删）。化用 ≤2 且 L3 以上，必附说明。
5. **核心表达优先**：动笔前先用一句大白话写"这首歌在说什么"；全篇至少 1 个贯穿物象（重复 ≥2 次）+ 1 句自造金句（无典、有物象、有动词）。**禁止把词写成典故拼贴**——一句一个典、或全篇找不到那句话，即返工。
6. **禁止伪古风三件套**：殇 / 琉璃 / 浮生 / 缱绻 / 流年 / 红颜 这类抽象词，全篇合计 ≤2 且必须有实义。
7. **金句必须具体**：具体物象 + 情感转折 + 可独立成句，三条缺一不算金句。
8. **不许现代词乱入古风句**：手机、地铁、加班这类词只在明确"现代国风"设定里出现。
9. **不复刻原作**：案例拆解只给手法；连续引用不超过 8 字并标注分析用途。
10. **每句至少一个动作或一个可触物象**，否则就是空话。
11. **交付前跑完 lint**（含 L13 用典密度、L14 核心表达），error 必须是 0。

## 五、`.lyr` 格式速查

```
[主歌A]
江:1 南:2 雨:3 | 落:4 青:1 石:2 巷:4
灯:1 影:3 里:3 | 我:3 数:3 你:3 的:0 船:2
```

- 每行一句；`字:调`，1 阴平、2 阳平、3 上声、4 去声、0 轻声/未知
- `|` 句内气口；`[段落名]` 分段
- 标点不写进词里；一句内不出现句号逗号

## 六、与配套技能《中国风音乐创作》的联动

两个技能各自独立，通过两种文件互通（都在本包 `scripts/` 里，纯本地运行）：

| 方向 | 命令 | 产出 | 交给谁 |
|---|---|---|---|
| 曲 → 词 | `python scripts/jianpu2lyricslots.py --input 江南雨.jp --out 江南雨-槽位` | `.slots.json` + `.slots.md`（每句字数、韵位、落音、声调建议） | 本技能按槽位填词 |
| 词 → 曲 | `python scripts/lyric2jianpu.py --input 我的词.lyr --key D --mode yu --cadence 6 --out 我的曲.jp` | 简谱骨架 `.jp` | 配套作曲技能的 `jianpu2midi.py` 导 MIDI |

**推荐闭环**：作曲技能出 `.jp` → 本技能生成槽位 → 填词 → lint → `lyric2jianpu` 微调成曲 → 回作曲技能导 5 轨 MIDI。

> 配套技能：《中国风音乐创作》（guofeng-music-composer）——定调式、写旋律、配五声化和弦、配器结构表、15 条旋律校验、多轨 MIDI 导出。

## 九、边界

- 本技能产出词稿与校验报告，不产出人声演唱音频；成曲需 DAW 与音源。
- 案例为教学与评论性质，只拆手法、不提供他人作品词稿全文。
- 化用与用典是否侵权由使用者最终负责，商用前请自行取得专业法律意见。
- 涉及真实人物、宗教、民族题材时，注意尊重与合规，不做戏谑化处理。

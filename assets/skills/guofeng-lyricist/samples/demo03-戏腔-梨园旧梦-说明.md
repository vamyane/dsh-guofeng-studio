# 示范 03 · 戏腔式《梨园旧梦》

> 场景：戏腔题材（角色＝伶人），练"主歌白嗓叙事 + 副歌戏腔拖腔 + 念白"三段式写法。
> 交付：`demo03-戏腔-梨园旧梦.lyr` + 本说明。

## 一、词作设定

| 项目 | 取值 |
|---|---|
| 主题 | 科班学戏 → 登台 → 戏班冷清 → 师父病 → 散场 |
| 角色 | 第一人称「我」＝戏子（**戏腔只在角色是戏中人时用**） |
| 体式 | 六段：主歌A 8 / 副歌一 8 / 主歌B 7 / 副歌二 8 / 念白 4 / 尾 4（共 39 行、353 字） |
| 辙口 | **江阳**（ang/iɑng/uang）一韵到底 |
| 戏腔设计 | 副歌「6 字高音短句 + 10–12 字拖腔长句」交替；副歌二用"一唱…八唱"数字排比 |

## 二、三段式的分工

| 段 | 声音形态 | 内容 | 要点 |
|---|---|---|---|
| 主歌 | 白嗓、叙事、字密 | 科班苦练、登台亮相 | 用具体动作（压腿、勒头、吊嗓） |
| 副歌 | 戏腔、高音短句 + 拖腔 | 唱词本身 | 短句给"亮"，长句给"拖"，拖腔字用平声 |
| 念白 | 半念半唱 | 师父的告诫 / 戏台的行话 | 4 句，短、口语、带行当味 |
| 尾 | 回到白嗓或轻戏腔 | 散场、人走、场子留下 | 落点在"空" |

## 三、戏腔词的硬规则

1. **角色先成立**：不是"戏中人"就关掉戏腔（见 `references/10-反模式与自检.md` 误区）。
2. **一段就够**：全曲戏腔集中在一到两个副歌，不全程。
3. **短句要能亮**：6 字以内、开口音（江阳辙正好开口）。
4. **拖腔字要平**：拖腔字的声调优先阴平/阳平，去声拖腔会"掉"。
5. **行当术语要有据**：蟒（蟒袍）、勒头、吊嗓、下场门——术语用错会露怯。本版为避开二级生僻字，把「旧蟒」写作「旧装」，语义不变，念白更顺口。

## 五、可复用到你身上的四条

1. **数字排比做节拍**："一唱…八唱"既叙事又定节奏，适合戏腔/燃系副歌。
2. **行头当意象**：蟒袍、靠旗、水袖、髯口——比"华丽""悲凉"有力。
3. **念白当转折**：念白放在副歌二之前，等于电影里的"画外音"。
4. **散场收束**：戏腔词的结尾最好落在"人散、台空"，不要收在"我很伤心"。

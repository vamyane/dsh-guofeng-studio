# 示范 04 · 词作曲《山月不知》

> 场景：**先有词，后谱曲**。词 → 简谱骨架 `.jp` → 交给配套技能《中国风音乐创作》导 5 轨 MIDI。
> 交付：`demo04-词作曲-山月不知.lyr`（词）、`demo04-词作曲-山月不知.jp`（骨架）、`demo04-词作曲-山月不知.mid`、本说明。

## 一、合作流（2 条命令）

```bash
# 1. 词 → 简谱骨架（依字行腔：按每个字的四声生成音高轮廓）
python scripts/lyric2jianpu.py --input 山月不知.lyr --key D --mode yu --cadence 6 --out 山月不知.jp

# 2. 骨架 → 5 轨 MIDI（用配套作曲技能）
python ../guofeng-music/package/scripts/jianpu2midi.py --input 山月不知.jp --out 山月不知.mid
```

## 二、词作设定

| 项目 | 取值 | 理由 |
|---|---|---|
| 主题 | 山寺夜读、故人远行 | 适合"淡而深"的羽调式 |
| 人称 | 第一人称「我」 | 信、炭火、山门都是"我"的视角 |
| 体式 | 五段体（主歌A / 主歌B / 副歌 / 副歌再现 / 尾） | 副歌必须再现一次，才记得住 |
| 辙口 | **人辰**（en/in/un）一韵到底 | 深沉、含而不露，适合"等"的情绪 |
| 用典/化用 | 题旨化用温庭筠「山月不知心里事」（《梦江南·千万恨》） | 只取"山月不懂人心"的题旨，未抄原句 |
| 句长 | 8–11 字，副歌 8–10 字 | 与 4/4 中速旋律匹配 |

## 三、结构

| 段 | 句数 | 句长 | 韵脚 | 作用 |
|---|---|---|---|---|
| 主歌A | 4 | 9/9/11/9 | 深·文·门·尘 | 场景（钟、灯、抄经、炭火） |
| 主歌B | 4 | 11/8/9/9 | 春·轮·门·痕 | 时间（少年之约 → 各自年轮） |
| 副歌 | 4 | 8/8/8/10 | 分·尘·问·门 | 情绪爆发（山月不知人间离分） |
| 副歌再现 | 4 | 8/8/8/10 | 分·人·问·痕 | 换两个物象（归人、柴门雪痕），同句式 |
| 尾 | 4 | 8/9/9/8 | 分·人·云·痕 | 回到"山月"，落到"雪落无痕" |

## 四、写作时可复用的手法

1. **一象一情**：钟声=时间、炭火=温度、信尾墨迹=旧情、山月=不懂人心的旁观者。
2. **对照推进**：主歌B "少年时约好看遍长安春 / 如今各自数着年轮"——时间跨度用两句完成。
3. **副歌换词不换句式**：再现段只换"风尘→归人""原来的山门→柴门前雪痕"，句式与韵脚不动（这是"记得住"的关键）。
4. **落点用物象不用抽象**：结尾落在"雪落无痕"，不写"我很想你"。
5. **忌**：不写"殇/琉璃/浮生"；不把"山月"当万能意象反复堆（全篇 5 处，已控制在阈值内）。

## 五、生成骨架的说明（重要）

`lyric2jianpu.py` 生成的是**骨架**，不是成曲：

- 音高按四声走向生成（阴平保持、阳平上行、上声先下后上、去声下行），句尾落到 `--cadence 6`（羽调式主音）。
- 骨架为保证"可唱"，会在长句中用间插音与休止填满小节，所以**听起来会有跳跃感**——这是给你改的起点，不是成品。
- 要变成能听的旋律：把 `.jp` 拖进作曲技能流程，按 `references/06-声韵与腔词.md` 微调句尾与重音音高，再补 `@chords` 与配器。

## 七、怎么改成你自己的

| 变量 | 怎么改 |
|---|---|
| 换辙 | 主歌/副歌整段换（不要段内换），改完跑 lint L1 |
| 换调式 | 宫调式（`--mode gong --cadence 1`）会立刻变"亮"，适合少年题材 |
| 加戏腔 | 副歌改「6 字短句 + 拖腔长句」交替，参考 `demo03-戏腔-梨园旧梦.lyr` |
| 不做曲 | 只交 `.lyr` 与说明，把 `.jp` 换成"给作曲者的旋律提示"（每个字建议音高区间） |

# 示范 01 · 曲填词《江南雨》

> 场景：**先有曲，后填词**。曲来自配套技能《中国风音乐创作》示范曲 `demo01-抒情国风-江南雨.jp`（D 羽调 · 72 BPM · 4/4 · 32 小节）。
> 交付：`demo01-曲填词-江南雨.slots.json/.md`（填词槽位）+ `demo01-曲填词-江南雨.lyr`（填好的词）+ 本说明。

## 一、合作流（3 条命令）

```bash
# 1. 作曲技能的曲谱 → 作词技能的填词槽位表
python scripts/jianpu2lyricslots.py --input 江南雨.jp --out 江南雨-槽位

# 2. 按槽位填词，写成 .lyr（每字标声调）

# 3. 带着槽位校验（句长、韵位、倒字一起查）
python scripts/lint_guofeng_lyric.py --input 江南雨.lyr --slots 江南雨-槽位.slots.json
```

## 四、填词时守的四条

1. **字数服从槽位**：每句字数 = 槽位「音节」数，长句可压到「最少」但不要超；超了唱不进去。
2. **韵脚服从押韵句**：只押槽位标 ✅ 的句子，辙口全篇锁在言前（年/烟/船/天/变/边/烟）。
3. **声调服从长音**：长音（拖腔）位放平声字（烟、天、年），仄声字（变、远、碎）不放长音。
4. **句尾不许空**：每个句尾都落在具体物象或动作上（烟、边、船、伞），不落在抽象词上。

## 六、怎么改成你自己的

| 变量 | 怎么改 |
|---|---|
| 换主题 | 保留槽位与韵辙，只换意象包（例：把"雨/苔/船"换成"雪/灯/马"→ 边塞版） |
| 换韵 | 用 `--slots` 报告的备选辙口（人辰）重填韵脚，其余不动 |
| 换人称 | 全篇「我」改「你」，但副歌要保留一句第一人称做落点 |
| 词不够 | 用槽位「最少」字数压缩短句；**不要加句**，加句等于改曲 |

# 示范 02 · 化用式《灯火阑珊》

> 场景：**主题先行**，写一首"化用宋词题旨但不抄原句"的词。对应词库路径 B（出处 + 不掉书袋）。
> 交付：`demo02-化用-灯火阑珊.lyr` + 本说明。

## 一、词作设定

| 项目 | 取值 |
|---|---|
| 主题 | 上元灯会重逢不遇（今昔对照） |
| 人称 | 第一人称「我」，副歌出现「你」 |
| 体式 | 主歌A 8 句 / 主歌B 8 句 / 副歌 8 句 / **副歌再现 4 句** / 尾 8 句（共 36 行） |
| 辙口 | **言前**（一韵到底） |
| 化用对象 | 辛弃疾《青玉案·元夕》的**题旨结构**：盛景 → 人海 → 寻找 → 阑珊；及欧阳修式"去年/今年"对照 |
| 引用情况 | **零原句**："蓦然回首"转写为"回头那一瞬"，只取逻辑不取字 |

## 二、结构推进

| 段 | 内容 | 手法 |
|---|---|---|
| 主歌A | 灯市、旧街、糖画摊、灯笼 | 器物轴铺陈，一句一个可摸的物 |
| 主歌B | 去年同一条街、挑纸鸢、说好明年再来 | 时间对照（去年/今年），动作具体（挑、走慢、数） |
| 副歌 | 人海里找背影、数灯、忽然有人喊我 | 把"寻找"写成有动作与时长的过程（数灯） |
| 副歌再现 | 灯亮到今天、还在老地方转、千百次回还 | 只换 2 个物象（亮到今天/回还），句式与韵脚不动，这是"记得住"的关键 |
| 尾 | 灯一盏盏灭、街空、明年还来不来 | 落点从"人"转到"灯/街"，留白 |

## 三、化用示范（怎么做到"像"而不"抄"）

| 原典要素 | 原典 | 本词做法 |
|---|---|---|
| 盛景 | 元宵灯会 | 保留灯市，换成糖画摊、纸鸢、灯谜 |
| 人海寻找 | 众里寻他千百度 | 写成"灯一盏一盏数到阑珊"——给寻找以**动作与时长** |
| 阑珊（将尽） | 灯火阑珊处 | 保留"阑珊"但改为"灯最暗的那一端"，把"在"翻译成"位置感" |
| 去年/今年 | 欧阳修《生查子》 | 用"去年也是这盏灯／今年换了人"对照，不引原词 |

> 判断标准：读过辛词的人会觉得"他懂这首词"，但找不出一句是抄的——这就是 L4–L5 化用。

## 五、可复用到你身上的三条

1. **给"寻找"一个动作和一个时长**（数灯、走了几遍、数到第几盏），比写"我找你很久"有力。
2. **证物法**：用一个上年留下的物（纸鸢、糖画钱、旧票根）承接"去年"，比写"回忆"具体。
3. **落点后移**：结尾不落在人，落在物（灯灭、街空），余味才留得住。

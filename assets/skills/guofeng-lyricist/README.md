# 中国风作词 · 使用说明（README）

给主题，出能唱的中国风词：**定韵辙句式 → 配意象典故 → 做化用炼字 → 排结构金句 → 四道校验 → 对接成曲**。

## 交付物

| 交付物 | 文件 | 说明 |
|---|---|---|
| 词稿 | `.lyr`（逐字标声调） | 可直接喂给谱曲脚本 |
| 可读版词稿 | Markdown | 分段、标韵脚，给人看 |
| 作词蓝图 | `作词蓝图.md` + `.json` | 韵辙、句式、意象包、典故候选、结构卡、金句位 |
| 校验报告 | Markdown | L1–L14 规则（含用典密度与反堆砌、核心表达）+ 门禁清单，结论行"可交付" |
| 化用与用典说明 | Markdown | 每处化用/用典的出处与用法 |
| 成曲路径 | 槽位表 `.slots.json/.md` 或简谱骨架 `.jp` | 与配套作曲技能对接 |

## 快速开始

```bash
# 1. 出作词蓝图（空输入也能跑）
python scripts/lyric_blueprint.py --demo

# 2. 校验词稿（有曲/有槽位可一起带上）
python scripts/lint_guofeng_lyric.py --input 我的词.lyr --report 校验报告.md

# 3. 手里有曲，要填词 → 生成槽位表
python scripts/jianpu2lyricslots.py --input 江南雨.jp --out 江南雨-槽位

# 4. 手里有词，要成曲 → 生成简谱骨架（交给配套作曲技能导 MIDI）
python scripts/lyric2jianpu.py --input 我的词.lyr --key D --mode yu --cadence 6 --out 我的曲.jp
```

四个脚本都是**纯 Python 标准库**，Python 3.8+ 直接跑，不需要 pip 安装；不联网。

## 目录

- `SKILL.md`：六步工作流与硬规则（模型读这个）
- `references/`：十一份可操作手册（速查卡、词体格律、意象、典故、化用边界与反堆砌、炼字修辞、声韵腔词、题材库、结构叙事、案例拆解、反模式自检）
- `scripts/`：四个脚本
- `samples/`：四组完整示范（曲填词、化用式、戏腔式、词作曲）

## 配套技能

《中国风音乐创作》（`guofeng-music-composer`）：定调式、写旋律、五声化和弦、配器结构、15 条旋律校验、多轨 MIDI。两个技能可双向对接：曲→填词槽位、词→简谱骨架。

## 适用与边界

- 适用：原创歌词、填词、歌词润色、短视频/短剧主题曲、戏腔段写作。
- 不适用：生成人声演唱音频；替他人作品写"相似但不侵权"的仿作；提供他人作品词稿全文。
- 案例拆解仅用于教学分析，引用不超过连续 8 字。

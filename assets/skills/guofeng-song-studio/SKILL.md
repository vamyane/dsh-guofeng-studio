# 中国风词曲工作室 · SKILL

本技能是**总入口**：先把需求分诊到「作词」或「作曲」，再用统一文件格式把两半接起来，最后一起过校验、一起交付。两个子技能各自完整，本技能只负责**分诊、衔接与总验收**。

## 一、先分诊：三种入口

| 用户给的东西 | 走法 | 谁负责 |
|---|---|---|
| 只有主题/情绪（"写一首中国风，写江南雨"） | 先出**词**定骨架 → 再用词生成简谱骨架 → 回作曲技能配和声/配器 → 导出 MIDI | 作词 → 作曲 |
| 已有歌词，要成歌 | 先跑作词 lint 清 error → `lyric2jianpu` 出 `.jp` → 作曲技能定调式、配五声化和弦、配器 → MIDI | 作词 → 作曲 |
| 已有旋律/编曲，要填词 | 作曲技能确认 `.jp` → `jianpu2lyricslots` 出填词槽位 → 按槽位填词 → 作词 lint → 回作曲导 MIDI | 作曲 → 作词 |
| 只要词 / 只要曲 | 不进本技能，直接用子技能 | 子技能 |

分诊只问**一个**问题（缺什么就补什么），不要连环追问；用户只给一句话时按默认值直接开工。

## 二、文件契约（两个子技能靠这三个文件互通）

| 文件 | 生产方 | 消费方 | 内容 |
|---|---|---|---|
| `.jp` 简谱 DSL | 作曲技能 / `lyric2jianpu.py` | `jianpu2midi.py`、`jianpu2lyricslots.py` | `@key/@mode/@scale/@meter/@tempo` + `@marks` 段落 + `@melody` 旋律 |
| `.lyr` 词稿 | 作词技能 | `lint_guofeng_lyric.py`、`lyric2jianpu.py` | 每行一句，`字:调`（1 阴平 2 阳平 3 上声 4 去声 0 轻声），`\|` 气口，`[段落]` 分段 |
| `.slots.json` 填词槽位 | `jianpu2lyricslots.py` | 作词技能 | 每句字数、韵位、落音、声调建议；人读版是 `.slots.md` |
| `.mid` 多轨 MIDI | `jianpu2midi.py` | DAW | 旋律 / 和声 / 低音 / 打击 + 段落 marker，GM 音色占位 |

**不允许自创格式**：手写 `.jp` 或 `.lyr` 时严格按上表语法；字段写错脚本会直接报错，不要绕过脚本手推参数。

## 三、闭环流程（推荐）

```
主题
 └─ 作曲：guofeng_blueprint.py       → 调式/结构/配器/和弦候选蓝图
     └─ 作曲：写 .jp 旋律
         └─ 作词：jianpu2lyricslots.py → .slots.json / .slots.md
             └─ 作词：按槽位填 .lyr
                 └─ 作词：lint_guofeng_lyric.py → 0 error
                     └─ 作曲：lint_guofeng.py（旋律/和声/交付三关）→ 0 error
                         └─ 作曲：jianpu2midi.py → .mid
                             └─ 总验收：交付清单逐项打勾
```

## 四、命令（脚本都在对应子技能目录下，纯 Python 标准库，不联网）

```bash
# 1 作曲蓝图（空 JSON 也能跑）
python scripts/guofeng_blueprint.py --input 需求.json --out-md 蓝图.md --out-json 蓝图.json

# 2 旋律校验（三关：旋律 / 和声 / 交付）
python scripts/lint_guofeng.py --input 我的曲.jp --report 校验报告.md

# 3 曲 → 填词槽位
python scripts/jianpu2lyricslots.py --input 我的曲.jp --out 我的曲-槽位

# 4 词 → 简谱骨架
python scripts/lyric2jianpu.py --input 我的词.lyr --key D --mode yu --cadence 6 --out 我的曲.jp

# 5 词稿校验
python scripts/lint_guofeng_lyric.py --input 我的词.lyr --report 校验报告.md

# 6 导出多轨 MIDI
python scripts/jianpu2midi.py --input 我的曲.jp --out 我的曲.mid
```

`scripts/...` 相对各自技能的基础目录解析（作曲技能目录 / 作词技能目录），执行前先 cd 到该目录，或写全路径。

## 五、硬规则（总验收）

1. **两套 lint 都必须 error=0**：旋律侧 M1–M15 + 九大误区；歌词侧 L1–L14（含 L13 用典密度、L14 核心表达）。
2. **词曲不分家**：副歌韵脚必须落在句尾长音上；句尾不倒字；一段一辙、段内不换韵。
3. **旋律侧硬规则照旧**：偏音 4/7 不做落音与长音；五声正音 ≥70%；六度以上大跳后反向级进；主奏民乐贯穿前奏/间奏/副歌；戏腔只在"戏中人"题材开。
4. **歌词侧硬规则照旧**：用典 ≤2 处且过"删典测试"；副歌首句与金句位 0 用典；伪古风抽象词合计 ≤2；金句必须"具体物象 + 情感转折 + 可独立成句"。
5. **不越界**：不替代 DAW 混音、不假装实录民乐、不产出人声演唱；MIDI 是 GM 占位，交付说明里写清换音源建议。

## 六、固定交付物（缺一即未完成）

1. 创作蓝图（`蓝图.md`）
2. 词稿 `.lyr` + 可读版（分段、标注韵脚字）
3. 简谱 `.jp`（旋律 + 段落标记）
4. 和弦级数表（级数 + 具体和弦 + 五声化改造点）
5. 配器与结构表（乐器 / 出场段落 / 频段 / 声像）
6. 两份校验报告（旋律侧 + 歌词侧，结论行都必须是"可交付"）
7. 多轨 `.mid`
8. 一页创作说明：题材怎么落到调式、主奏为何选它、下一版可换的 2–3 个变量

## 七、子技能分工

- 作曲：`guofeng-music-composer` —— 调式与音阶、简谱旋律、五声化和弦、配器结构表、15 条旋律校验、多轨 MIDI。
- 作词：`guofeng-lyricist` —— 韵辙与句式、意象与典故、化用与炼字、结构与金句、14 条词稿校验、填词槽位。

需要细节时读对应子技能的 `references/`，不要在总入口里重复推参数。
